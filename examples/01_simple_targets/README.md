# Example 01: Simple Targets

An interactive target-popping demo game for projection mapping and touch/laser tracking.

## Features
- Fixed 1080p SubViewport rendering.
- Hit detection via Area2D collision with physical mouse or laser tracking.
- Interactive score tracking.
- Live keystone calibration with `TAB`.

## Running the Demo
Open the project in Godot 4 and run `examples/01_simple_targets/main.tscn`.
