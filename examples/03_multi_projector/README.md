# Example 03: Multi-Projector Spanned Setup

Demonstrates a 2-projector spanned screen configuration with edge blending.

Uses `addons/openprojmap/shaders/edge_blend.gdshader` to blend the overlapping boundary seamlessly across physical displays.

## Running the Demo
Open the project in Godot 4 and run `examples/03_multi_projector/main.tscn`.
